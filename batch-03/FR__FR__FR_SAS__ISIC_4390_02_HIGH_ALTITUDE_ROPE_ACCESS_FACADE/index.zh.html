法国税法并未提供类似美国“查盒”或选择性透明度的制度。SAS公司根据《法国税法典》第206(1)条被归类为实体层级纳税人，需缴纳公司所得税，适用标准25%的税率，且不能选择穿透纳税待遇。现行可选择的法定优惠包括：（i）对符合条件的小型和中型企业（SMEs），年营业额不超过1000万欧元的，其应税利润前42,500欧元部分可享受15%的所得税率（《法国税法典》第219-II条）；（ii）在法国母公司持股比例不低于95%的情况下，可选择“财政合并”（intégration fiscale），实现集团层面的统一应税结果（《法国税法典》第223-A条）；（iii）对于符合条件的母子公司持股比例在5%及以上的情况，可选择“母子公司制度”（régime mère-fille）的持股免税待遇；（iv）在特殊情况下，可依据政府间协议选择整体或合并利润（bénéfice mondial/consolidé）的计算方式；（v）对于具有财务、经济和组织上紧密联系的关联企业，可选择增值税统一申报（assujettissement unique en TVA）（《法国税法典》第1693-ter条）；（vi）若符合研发支出门槛，可选择作为“创新青年企业”（Jeune Entreprise Innovante, JEI）享受3年全额或部分所得税豁免；（vii）在母子公司制度下，股息分红可享受较低税率。法国税法中不存在可选择的混合性税务差异调整安排：法国已强制实施ATAD（欧盟指令2016/1164），因此混合性支付、反向混合性支付以及双重扣除差异均被强制中和，纳税人无法通过自行选择来激活或取消此类安排。

已设立的供应商可享受小企业免税待遇（增值税豁免权），根据《法国刑法典》第293-B条：商品销售的年营业额上限为85,000欧元，服务提供则为37,500欧元。然而，对于未在法国设立的外国供应商，该门槛为零：只要在法国发生任何应税供应，即从第一欧元起必须强制进行增值税登记。根据《法国刑法典》第259-3条，与不动产相关的服务——包括绳索作业外墙维修、结构玻璃更换以及超高层摩天大楼的安装工程——无论供应商是否在法国设有常设机构，只要不动产位于法国境内，即在法国征税。而跨欧盟的远程商品销售进入法国，仅在达到10,000欧元的欧盟“一站式”（OSS）统一门槛时才需征税；而针对法国不动产的建筑服务，则从第一欧元起即需征税，不存在任何免税门槛。

跨境出口 0% 零税率申报条件

根据《欧盟海关法》第262-I条，以海关清关为证明的欧盟境外商品出口属于零关税（可扣除费用且无需缴纳关税）；而根据第262-ter条，具有客户有效的欧盟增值税识别号及运输文件证明的欧盟内部运输则属于免税范围。对于绳索进入式外墙作业，在法国境内的不动产上进行的作业属于法国供应规则的范围，依据《法国税收法》第259-3条，此类作业需缴纳20%的增值税；对于国内外墙作业则无法享受零增值税待遇。零费率优惠仅适用于以下情况：(i) 未安装即销售并出口的预制玻璃/外墙模块；(ii) 单独收费并出口用于法国境外工程的材料；(iii) 完全在欧盟境外完成的外墙施工服务。这些服务属于法国增值税适用范围之外，并非正式零税率服务。对于向外国客户提供的B2B服务，则适用一般条款。259-A 计算机生成图像供应规则规定，供应商必须证明接收方位于法国境外，并证明该供应与法国不动产无关；在法国摩天大楼上的建筑合同不能被重新视为出口服务。

强制性的B2B电子发票和电子报告制度改革（2023年财政法及第2022-1299号法令；CGI第289bis条）：自2026年9月1日起，所有在法国成立的纳税主体必须能够接收结构化电子发票；大型和中型企业自2026年9月1日起必须开具电子发票，而小型/微型企业则自2027年9月1日起必须如此。电子发票必须通过国家公共发票平台或经过认证的私人电子化平台进行传输，使用强制性的API接口（API Facturation / API Partenaires），并采用Factur-X 1.0、UBL 2.1或CII 16B等强制格式。税务审核几乎为实时进行：交易和支付数据（电子报告）必须在发票开具后的第二天内，且在支付后10天内传送到DGFiP；公共发票平台作为中央税务数据中心。发送给法国公共机构的B2G电子发票还必须通过Chorus Pro平台进行传输，且需提供强制性的服务代码。虽然零税率出口发票可以享受信贷优惠，但仍需遵守相同的电子发票和电子报告传输要求。

外汇管制与央行政策诊断

经常项目兑换自由度

法国在经常项目和资本项目交易方面均具备完全的法律和实际可兑换性，仅受欧盟《共同商业政策条约》第63条关于资本自由流动的规定以及法国审慎监管或国际收支报告义务的限制。对于境外股权认购或利润汇出，无需中央银行审批；以欧元计价的收入无需进行外汇兑换、分配或交割。向非居民股东分配股息在外汇方面不受限制，前提是SAS遵循法国公司分红的法定程序，核实欧盟母公司-子公司指令或双边税收协定中适用的预扣税减免条款，并满足DAC6/MDR或反滥用文件要求。仅在战略和国防领域、两用物品、国家安全审查或欧盟、联合国、OFAC以及法国统一制裁清单所实施的特定金融制裁情况下，存在对资本流动的限制。

出口外汇强制结汇要求

法国未规定必须将出口收入交还，也未强制要求将外汇转换为欧元。来自跨境绳索作业外墙服务的出口收入，可存入经授权的金融机构开设的专用外币账户，且无最长持有期限。不存在最低兑换比例，也无汇回期限。然而，所有跨境资金流动，包括出口收入，均需遵守法国国家银行的国际收支报告制度以及欧盟/联合国制裁筛查要求；通常由中介银行承担报告义务，除非该SAS自身被指定为申报主体。

央行监管: 法国银行（法国国家中央银行及欧元体系外汇管理机构）；与财政部总署在政策协调方面合作，并依据《货币与金融代码》第L.411-1至L.411-5条及第R.411-1至R.411-7条，通过审慎监管局实施审慎监管。

inbound权益和股东垫款必须通过SWIFT MT103客户信用转账方式传递，如银行间路由要求，则使用MT202文件进行传输。资金应由非居民母公司或集团财务中心，通过接收方一级银行处的SAS IBAN进行转账。执行银行必须将交易归类为法国银行国际收支直接投资项目，并填写相应的法国主题/业务目的代码；转账参考信息必须明确说明股票认购情况、董事会决议、股票类型以及垫款方信息。在确认金额之前，银行会核实以下事项：账户用途是否为资本托管或运营账户；当前的RBE/UBO记录；汇款人身份是否与公司决议一致；资金来源证明；针对欧盟、联合国和OFAC的制裁及禁运情况，以及法国的相关名单；以及所陈述的目的是否与SAS公司的企业合同和建筑合同相符。无需事先持有中央银行外汇许可；该机制属于声明性机制，而非基于授权的机制。对于法国及欧洲经济区（EEA）交易对手方的付款，财库应通过T2/欧元体系清算的SEPA信用转账及SEPA即时信用转账，并每日与SAS的银行账户号码（RIB/IBAN）及增值税参考信息进行对账。对于非EEA地区的贸易结算，应使用SWIFT GPI MT103客户信用转账，如需则使用MT202报文，进口幕墙系统材料及专用设备应通过SWIFT MT700/MT707开立不可撤销的跟单信用证，并适用2020年国际贸易术语（Incoterms 2020）。付款须以符合规定的发票、运输单据、保险单及竣工证书等文件作为依据。在交易对手双方银行均支持的情况下，可依据ICC URBPO 750规定的银行付款义务作为跟单信用证的替代方案。每项付款指令均须包含受益人BIC/IBAN、法国银行报告目的代码、底层项目或合同编号，以及增值税/SIRET/TVA标识码，以确保审计可追溯性。关于采购和分包商付款产生的EUR/USD、EUR/GBP、EUR/CNY以及EUR/CHF风险敞口的普通远期合约，这些合约由ISDA/CSA协议或与持牌银行交易对手签订的法国市场主协议进行交易。外汇掉期用于匹配外币收入与以欧元计价的运营支出现金流用于对非欧元跨境公司股东贷款及外币资本敞口进行长期资产负债表对冲的跨境货币互换香草型金融期权，包括长期期权和零溢价合约，需经银行信贷审批，并涉及相关交易或资产负债表风险只有当相关货币不可兑换或境内交易受限时，才采用非交付远期交易方式。该交易需通过法国银行授权的信贷机构或受EMIR/IFR监管的欧盟/英国投资公司进行，并需提供对冲相关文件，且不存在独立投机交易意图

电商与网关结算适配度: 可行性评级：运营资金支付方面为有条件/中等；资本保证金和法定资本承诺方面为低。经法国或欧盟金融监管局（ACPR）授权或享有PSD2/电子货币指令“通行证”的法国或欧盟电子货币机构，可持有受保护资金并执行SEPA/SWIFT支付，但不得接收存款或提供信贷。仅以数字电子货币机构（Digital EMIs）作为证据证明SAS资本保证金账户具备银行实质是不可接受的，此类机构亦不得签发跟单信用证或银行保函；若一级欧元结算银行作为底层资金管理和清算对手方，则数字电子货币机构可作为仅用于执行的支付通道。
