主管官方机构、法典依据、验资锁资规程与首期董事会决议范本。

法定实缴资本与验资锁资账户流程 免验资锁资账户

SAS没有法定的最低股本要求。公司章程必须规定在成立时需全额认购的资本额。对于现金出资，在认购阶段必须支付至少50%的名义金额；剩余部分可在五年内被提取使用。已支付的现金出资须以银行存款证明或公证存款方式作为凭证，直至完成注册为止。

注资与解冻路径: 涵盖灭火器、紧急出口、报警系统及电气安装的工作场所消防安全认证；货架或夹层结构荷载验证；根据法国劳动法规定的职业健康与安全检查清单。包括预防肌肉骨骼方面的风险，以及当场所对员工或第三方开放时为残疾人提供进入通道。

实缴资本规则: SAS没有法定的最低股本要求。公司章程必须规定在成立时需全额认购的资本额。对于现金出资，在认购阶段必须支付至少50%的名义金额；剩余部分可在五年内被提取使用。已支付的现金出资须以银行存款证明或公证存款方式作为凭证，直至完成注册为止。

董事会首期决议范本 (Pro-Forma First Board Resolution)
由唯一股东根据法国商业法第L.227-1条的规定执行解决如下事项：(1) 采纳公司章程，并按要求认购和缴足所有注册资本；(2) 注册地址定为[地址]，所属管辖法院为[商业法院]；(3) [姓名]被任命为公司主席，拥有代表该SAS的所有权力，可开设银行账户、签订合同以及完成所有注册、税务和社会手续。主席有权采取一切行政措施，并将日常事务权委托给法律代表。

官方税号申请基础设施

主管税务局

法国财政部（DGFiP）。主要在线门户为impots.gouv.fr；外国企业通常通过外国企业税务服务部（SIEE）办理法国税务登记及增值税相关事务。

电子政务申报门户

法国的SAS公司需通过相应的公司设立程序进行注册，并从国家企业登记系统获得SIREN和SIRET编号；随后，必须向法国税务与财政管理局（DGFiP）完成税务登记手续，如需则取得法国增值税识别号。在法国提供应税供应的外国实体，应在开始此类供应前向法国增值税登记处（SIEE）申请增值税登记，需提供法律存在证明、公司章程、业务活动说明、代表人的身份及授权文件，以及与法国相关的应税交易详情。一般而言，非欧盟设立的商业实体必须指定一名法国税务代表，除非存在适用的相互协助安排或法定豁免情形。欧盟设立的商业实体通常无需指定此类代表。增值税号码本身并不构成常设机构，也不决定企业所得税的居民地位。

通常情况下，法国的SAS公司需缴纳法国公司所得税（所得税，IS）。符合条件的小型公司可在满足法定条件、股东及业务活动测试以及有限期选举要求的前提下，临时选择适用个人所得税制度。这并非美国式的“检查盒子”选举。法国没有针对外国实体的普遍性“检查盒子”机制来确定其法律实体性质；对于外国实体的税务处理，遵循法国税法的定性规则以及适用的双边税收协定。此外，混合性不匹配规则可能拒绝扣除或要求根据法国及欧盟反混合性法规进行税项并入。

强制登记营业额门槛 (Nexus)

年营业额为8.5万欧元，适用于货物供应及某些类似活动；服务类活动的年营业额则为3.75万欧元，均适用国内小型企业增值税豁免的法定条件及相应的容忍额度。这些门槛通常不适用于在法国开展应税供应但尚未设立的业务：自首次产生应税交易起，可能需要进行注册并实施增值税会计。此外，可能适用欧盟跨境中小企业特殊安排或针对具体交易的规则。

跨境出口 0% 零税率申报条件

从法国向欧盟以外目的地出口货物，若供应商能够证明货物已运出欧盟，并满足相关文件和发票要求，可享受免税待遇（实际税率为0%增值税）。欧盟内部供应则适用不同的规则，通常要求货物运往另一成员国、客户具备有效的增值税识别号，并提供相应的证明材料。服务出口并非自动适用零税率：服务的征税与否通常依据“供应地”规则确定，对于企业间服务，一般在业务客户设立于欧盟境内时即视为征税，但存在法定例外情况。退货或再出口的物流问题需根据具体交易情况进行分析，仅凭退货或再出口行为本身，并不能直接认定符合出口免税或进口减免的资格。

  • 法国/欧盟出口海关申报及海关办公室出口证明或同等电子出境确认
  • 商业发票、装箱单以及标明货物并将其与销售或退货交易关联的文件
  • 运输单据，如提单、航空运单、CMR运单或承运人交付及出境记录
  • 客户订单、合同、退货授权以及支持货物流转和所有权的仓库或库存记录
  • 与交易相关的银行或支付记录； inward remittance certificate 不是法国通常规定的出口增值税文件

法国通常不实行增值税发票的实时清关或强制性数字盖章。国内企业间电子发票的推行正在逐步实施：自2026年9月1日起，所有企业必须能够接收符合规定的电子发票，大型和中型企业的企业必须开具电子发票；中小企业和微型企业的电子发票开具则计划自2027年9月1日起实施。纳入监管范围的发票必须使用经授权的平台和符合规定的格式。电子报税适用于特定交易，包括相关的企业对消费者交易和跨境交易，具体实施按阶段推进。外国企业应核实其在法国的交易是否属于国内适用范围。

法国对出口收入没有普遍适用的外汇汇回期限。上述零值表示不适用180天或其他普遍期限，也不意味着存在必须汇回的期限。未经证实或虚假的出口免税申明可能导致增值税重新评估、滞纳金及罚款；罚款的金额取决于违规的性质、金额及意图，故意或欺诈性行为可能导致更严重的处罚。进项增值税抵扣或退税也可能被拒绝或追回。应根据法国适用的法律规定保留海关和税务记录，并在审计时提供相关文件。

外汇管制与央行政策诊断

经常项目兑换自由度

法国对资本和交易的法律可兑换性提供完全保障；欧元可自由流通，无需事先获得中央银行批准即可进行股权认购、股息汇出或清算所得的支付。法国的外国投资审查制度（第2019-1590号法令，第L151-3条及以后条款，CMF）仅适用于战略性行业，而国际标准行业分类（ISIC）5229类别的逆向物流不属于敏感领域，因此无需事先获得投资许可。在实际利润汇出方面，主要存在文件性障碍，包括：可分配盈余为正、有效的公司利润分配决议、符合FATCA/CRS的自我声明，以及适用的非居民股息预扣税（25%至30%），除非通过税收协定予以减免，或根据欧盟母公司-子公司指令豁免（母公司持股比例不低于10%，且持续满24个月）。

出口外汇强制结汇要求

法国没有强制要求将出口收入上缴或兑换的比率规定，外币应收款项可在未经中央银行指令的情况下保留于境内以货币计价的账户中。仅凭法定报告义务即对运营方产生约束：凡在自然月内累计跨境收付款（包括收入和支出）达到或超过75万欧元的居民实体，须在月末后20个营业日内通过MERIDIA渠道向法国银行（Banque de France）进行电子申报（《法国金融法典》第L.141-1至L.165-2条）。从外国商户处收回的退货退款流动，按国际收支统计归类为服务贸易或再出口流动，此类收入无需强制兑换。

股息预提税 (WHT)

对非居民支付的股息适用30%的国内标准预提税（《国际税收协定》第119条之二）。对于欧盟母公司持有SAS股份比例不低于10%且持股期限不少于两年的情况，可适用欧盟母公司-子公司指令的豁免；根据税收协定，预提税率可降至0%至15%。
