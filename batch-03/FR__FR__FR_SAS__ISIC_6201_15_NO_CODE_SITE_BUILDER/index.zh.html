外汇管制与央行政策诊断

经常项目兑换自由度

法国实行欧盟资本和经常账户自由流动政策，欧元具有完全可兑换性。对于非居民而言，经常账户支付（如股息、特许权使用费、服务费）不设外汇管制、预扣税或审批要求，前提是其底层税务合规性（例如反滥用审查的预先申报）已得到满足。资本账户业务（如股权注入、贷款）在欧盟范围内不受限制，仅当单月金额超过15,000欧元时，需向法国国家银行（Banque de France）进行行政申报，以满足统计目的。利润汇回的障碍较小，通常只需证明可分配储备，并遵守反洗钱（AML）资金来源核实要求。

出口外汇强制结汇要求

没有法定的转让或强制兑换要求。出口商可以保留外币账户，但如果单次交易金额超过12,500欧元，或者属于事先申报的项目，则必须向法国银行报告出口收入，以用于国际收支统计目的。无需执行强制性的欧元兑换比例。

法定所得税率 (CIT)

企业所得税税率为25%。对于企业所得税税负超过76.3万欧元且不符合减免条件的企业，还需缴纳3.3%的社会贡献，实际税负约为25.83%。

股息预提税 (WHT)

通常情况下，法国SAS向非居民股东支付股息及其他类似分配，需适用25%的预提所得税，但存在豁免、欧盟规则、税收协定以及反滥用规定。向符合条件的欧盟或欧洲经济区母公司支付的股息，如满足法定持股比例、持有期限及反滥用条件，可享受国内参与豁免。符合条件的母公司通常须直接或通过符合条件的安排持有分配公司至少10%的资本，并满足必要的持有期限条件或提供相应的承诺。

转让定价与经济实质

主文档/本地文档门槛: 年营业额或总资产达到1.5亿欧元，或属于满足法定门槛的集团，通常会触发完整的转让定价文档要求，包括本地文件和主文件内容。年营业额或总资产达到5000万欧元，或纳税人属于满足法定条件的集团时，通常需提交转让定价声明（表2257-SD）。跨国集团若合并年度收入达到至少7.5亿欧元，通常需进行按国家报告。

经济实质审查范围: 法国并未设立与阿拉伯联合酋长国经济实质制度（ESR）完全相同的独立经济实质制度。然而，在法国的反滥用规则、受益所有权分析、税收协定权利、常设机构原则、受控外国公司规则、反混合交易规则、利息限制规则以及一般反滥用原则中，实质因素均具有重要影响。SAS公司应确保在商业需要的情况下，维持法国层面的决策机制、人员或外包运营能力、场所或运营基础设施，对软件及客户活动实施实质性功能控制，对银行账户实施控制，保管董事会记录、合同以及实际服务的证据。若存在仅形式存在而无真实职能、风险、资产或决策权的中转实体，可能丧失税收协定待遇和扣除权，并可能引发税务重审、常设机构认定或预提税义务。

致命合规红线与董事个人责任

逃税及虚假报税

法定制裁: 普通税务欺诈行为可能面临最高五年的监禁和高达50万欧元的罚款，此外还需进行税务重新评估、支付利息及处罚，还可能被处以企业罚款。而严重行为，包括有组织性的欺诈计划或大量资金在海外隐匿，则可能面临最高七年的监禁和高达300万欧元的罚款，但需符合法定条件。

董事个人责任: 董事及事实上的管理者可能面临刑事责任、依据法定管理责任规则产生的民事税务责任、个人出资责任、资产追缴、职业禁止，以及在严重情况下被实施旅行限制或预先羁押。公司人格否认制度不能免除其故意参与欺诈的个人行为。
转移定价操纵与利润转移

法定制裁: 法国税务机构可能会重新评估应税利润，拒绝扣除项，征收预扣税、利息和罚款，实施转让定价文档违规处罚，并根据反滥用原则对交易进行重新认定。

董事个人责任: 董事若明知地批准虚假或滥用的交易、隐瞒记录或组织破产以逃避税务追偿，可能面临个人责任。因管理不善而可能承担民事责任，若其行为构成欺诈或伪造，则可能承担刑事责任。
永久性机构隐瞒

法定制裁: 政府可以设立法国常设机构，将利润分配给法国，重新评估公司所得税及工资相关负债，实施预扣义务、利息和罚款措施，并质疑条约保护条款。

董事个人责任: 董事可能因故意隐瞒、提交虚假文件或未保持法定记录而承担个人责任。刑事责任通常要求存在额外的欺诈行为，而不仅仅是对常设机构认定问题的技术性分歧。
非法分红或隐性分配

法定制裁: 后果可能包括追回非法分配款项、公司法制裁、拒绝扣除、股息重新定性、预提税、税务处罚，以及可能的公司破产或滥用公司资产诉讼。

董事个人责任: 批准非法分配的董事可能需承担返还财产、损害赔偿及破产责任，并可能因滥用公司资产或提供误导性财务报告而面临刑事处罚。旅行限制或监禁取决于具体的刑事犯罪及法院判决。
洗钱及收益隐匿

法定制裁: 洗钱行为可能面临最高五年的监禁和最高50万欧元的罚款；严重洗钱行为则可能面临最高十年的监禁和最高75万欧元的罚款，具体取决于法定条件。相关资产可能会被冻结或没收。

董事个人责任: 明知参与的董事及受益所有人可能面临刑事起诉、资产没收、资产冻结、职业禁入、民事赔偿及司法旅行限制。公司可能被处以公司刑事罚款和资产没收。
反洗钱及受益所有权缺失

法定制裁: 制裁措施可能包括行政罚款、禁令、账户或业务限制、对违规行为的报告要求，以及在行为有助于洗钱、欺诈或虚假申报时面临的刑事后果。适用的规定取决于该机构是否属于法国反洗钱法律规定的义务实体。

董事个人责任: 法律代表可能因故意作出虚假的权益所有者声明或参与洗钱行为而面临个人罚款或刑事责任。此外，还可能面临民事责任、董事资格取消以及资产追回等后果。
增值税欺诈与支付平台隐瞒

法定制裁: 后果包括增值税的征税、滞纳金、根据行为情况通常在10%至80%之间的罚款、不予抵扣进项税、在特定情况下承担共同责任，以及对故意逃避行为实施的刑事欺诈处罚。

董事个人责任: 董事可能因故意欺诈性增值税行为、虚假记录或与破产相关的不当行为而承担个人责任。公司责任限制不适用于故意的个人刑事行为。
虚假会计记录和文件销毁

法定制裁: 如果虚假账目或销毁证据属于欺诈、破产或洗钱行为，该公司可能会面临会计法制裁、税务重新评估、针对其的证据推定、罚款以及刑事处罚。

董事个人责任: 董事、会计师及实际管理者可能面临监禁、罚款、董事资格取消、民事赔偿、返还财产以及破产损失的赔偿责任。在法律有据的情况下，可能被实施司法旅行限制。
贿赂、腐败及不当商业支付

法定制裁: 法国的腐败犯罪行为可能面临长期监禁、高额罚款、企业刑事责任、资产没收、被排除在公共采购之外以及非法支付的税务不予认可。具体处罚取决于是公职人员还是私人人员的贿赂行为，是境内还是境外行为，以及是否存在加重情节。

董事个人责任: 董事及员工可能面临个人刑事起诉、罚款、监禁、资格取消，并可能被没收财产及承担民事赔偿。公司有限责任不保护明知参与的行为。
制裁与出口管制违规

法定制裁: 可能的后果包括刑事罚款、监禁、资产冻结、没收、付款限制、行政强制措施以及许可资格丧失，具体取决于适用的欧盟和法国制裁制度。

董事个人责任: 董事及合规官可能因故意或重大过失违反规定而被追究个人刑事责任。一旦认定构成法定犯罪，可能面临民事赔偿、没收财产、旅行限制以及监禁等处罚。
