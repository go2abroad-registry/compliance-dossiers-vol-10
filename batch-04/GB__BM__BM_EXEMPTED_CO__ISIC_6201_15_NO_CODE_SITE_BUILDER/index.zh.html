法定实缴资本与验资锁资账户流程 强制验资锁定

百慕大法律并未规定最低注册资本要求。被豁免的公司必须至少拥有一股已发行股份；公司章程中必须明确规定的法定股本金额（通常为12,000美元或等效金额用于费用分类），且无需支付托管费、保证金或资本化费用。百慕大货币局要求，当所有股东均为非居民时，公司必须被指定为“非居民公司”。

注资与解冻路径:

实缴资本规则: 百慕大法律并未规定最低注册资本要求。被豁免的公司必须至少拥有一股已发行股份；公司章程中必须明确规定的法定股本金额（通常为12,000美元或等效金额用于费用分类），且无需支付托管费、保证金或资本化费用。百慕大货币局要求，当所有股东均为非居民时，公司必须被指定为“非居民公司”。

董事会首期决议范本 (Pro-Forma First Board Resolution)
首次董事会决议——经全体书面一致同意：决议通过，批准上述认股；根据各认购人姓名所列的股份予以分配并发行，且该等股份已全额缴付；并授权秘书将股份分配的法定文件提交公司注册处。进一步决议：公司注册办事处设立于[百慕大地址]，由已获许可的公司服务提供商负责维持法定账册和记录。进一步决议：任命[姓名]为董事，任命[姓名]为秘书，二人任期直至被替换为止，并授权其代表公司开设银行及支付处理账户，以及委任专业顾问。

电子政务申报门户

伯利兹豁免公司依据1981年《公司法》设立；公司注册处将自动颁发公司注册号码，该号码即为法定税务识别号（TIN）。由于伯利兹不征收增值税/商品与服务税（VAT/GST），因此不存在增值税识别号，也无需在国内进行增值税登记。对于工资税，一旦公司开始向位于伯利兹的员工支付薪酬，就必须通过www.gov.bm向税务专员办公室注册为雇主（无需达到最低 payroll 阈值）。对于符合范围的跨国企业集团（合并收入≥7.5亿欧元），自2025年1月1日起生效的财政年度起，需根据2024年《税务管理法》向财政部申请企业所得税（CIT）税务识别号及电子申报账户。非金融类实体（如无代码网站构建平台）无需进行FATCA/CRS登记，也无需申请全球识别号码（GIIN）。

税收豁免区——根据1966年《豁免企业税收保护法》，处于该状态的公司可自动获得所得税、资本收益税、公司税及预扣/分配税的豁免，有效期至2035年3月31日。适用范围仅限于百慕大来源的工资税以及实物进口的关税；数字出口收入则无需纳税。对于小型企业而言，不存在企业层面的税收制度；2023年《公司所得税法》（15%税率）仅适用于合并收入至少达7.5亿欧元的大型跨国企业集团中的各个子公司，而ISIC 6201低代码构建工具的运行规模低于此标准，因此不适用该法律。

支持身份选举表单

对于1966年税收保护保障制度而言，无需进行任何选择；该制度自动适用于所有被豁免的公司。百慕大没有美国式的勾选式制度，当地法律也不允许进行穿透式分类选择。仅针对2023年CIT法案所涵盖的集团而言：可以选择适用过渡性国家별报告安全港制度，也可以选择由当地组成实体代表该集团进行申报，此外还有合格国内最低补充税机制可供使用。由于小型企业被豁免的公司没有重要的所得税基础，因此不存在混合不匹配选择。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

没有——百慕大不征收增值税、 GST或销售使用税。唯一的间接税是1971年《海关关税法》规定的进口关税（针对进入百慕大的实物商品），以及1995年《工资税法》规定的雇主一方所缴纳的税款，后者属于直接工资税，而非间接税。由百慕大豁免公司提供的跨境数字服务（如无代码网站构建服务）则不受任何百慕大间接税的影响。另外，根据英国法律，向英国消费者提供的B2C数字服务可能需要缴纳英国增值税（非注册供应商的阈值为每年8,818英镑）——这是英国的税收义务，而非百慕大的义务。

强制登记营业额门槛 (Nexus)

不适用——百慕大没有增值税交易额门槛，也没有在百慕大的间接税注册机制。关税是按进口交易单计算的；对于纯粹的数字服务出口商来说，没有通用的进口商注册门槛。无论薪酬水平如何，只要雇佣了任何位于百慕大的员工，就需进行雇主工资税注册。所有来自视觉网页模板和低代码SaaS订阅的出口收入完全属于百慕大海关和工资税管辖范围之外。

跨境出口 0% 零税率申报条件

不适用——由于没有增值税或GST，因此没有可以申请的0%出口税率，也没有需要抵扣的出口增值税，更没有可以退还的进口增值税池。根据ISIC 6201/NAICS 511210分类的无代码网站构建服务出口，自动属于不属伯明迪征税范围的商品，因此永远不受伯明迪关税的约束。如果该实体还出口实体硬件或媒体产品，这些商品在离开伯明迪时无需缴纳出口税；只需进行准确的海关出口记录即可。因此，整个出口收入在伯明迪层面是免税的。

  • 纯数字服务（无代码网站构建平台）：根据百慕大法律，无需提交强制性文件——无需海关出口申报、无需提单，也无需境内汇款证明。
  • 从百慕大出口的实物商品（例如服务器、预装媒体）：通过百慕大海关管理系统提交百慕大海关出口申报单，商业发票、装箱单和提单。

在百慕大，不存在实时财政结算、电子发票制度、数字印章或B2B交易电子报告机制。实物进出口仅通过百慕大海关管理系统进行电子结算。通过Stripe Billing或Paddle生成的数字服务发票无需政府审批，也无需API集成，更无需与税务机关进行序列号验证。

由于不存在增值税制度，因此不会存在增值税出口零税率欺诈或资金追回问题。剩余的合规风险包括：(i) 1971年海关关税法规定的处罚，包括对未正确申报的实物出口或进口征收高额法定罚款及没收财产；(ii) 若未经注册就雇佣百慕大员工，则需遵守1995年工资税法和2024年税务管理法规定的利息及迟报处罚；(iii) 对于超过7.5亿欧元的集团，根据2023年公司所得税法，若低估了追加税额或迟报，将面临处罚，该规定仅适用于2025年1月1日或之后开始的纳税年度。1966年免征税企业税收保护法禁止对获准享受优惠的小型企业追溯征收收入/资本税；此外，百慕大没有外汇管制法规，因此不存在法定的外汇汇回期限，也不存在基于汇款的资金追回情况。

外汇管制与央行政策诊断

经常项目兑换自由度

本外币账户均实现完全且自由的可兑换。百慕大于2005年通过《外汇管制（废除）法案》废除了外汇管制；百慕大元（BMD）实行类似货币局制度，与美元保持1:1的固定汇率，由美元储备作支撑。对于跨境投资、股息宣告、利润汇回、集团间贷款以及清算分配，均无需获得百慕大金融管理局（BMA）的批准。实际操作中仅存在有限的障碍，主要涉及银行层面针对高风险交易对手国的内部强化尽职调查、CRS/FATCA透明度分类，以及利润从免税实体汇回时所需提供的经济实质文件证明。

出口外汇强制结汇要求

没有。百慕大对出口收入或任何外币收入不实施任何法定上交、兑换或保留限制。来自支付服务提供商（如Stripe Billing、Paddle）的收入可以无限期地存放在符合BMA许可要求的账户中，账户货币可以是美元、百慕大元、英镑或欧元；无需强制将其兑换成百慕大元。

无需获得外汇管制授权。入境资本注入应通过SWIFT MT103方式进行，由英国或全球汇款方使用OECD BPM6目的代码“611 – 直接投资：资本投入”进行汇款；英国汇款方的银行可以将其归类为国内出境汇款目的类别，如“直接投资”或“资本投入”。百慕大接收银行（Butterfield/汇丰银行）将在收到董事会决议、根据《1981年公司法》提交的股份分配表格以及汇款方提供的资金来源声明后，将美元/百慕大元资本账户资金计入该账户。转账时应注明实体的完整法定名称和账户号码；银行确认书的扫描件即可满足BMA的事后监管要求。对于供应商付款、承包商结算、云基础设施费用以及利润汇回等事务，主要支付方式为SWIFT MT103格式的支付指令（或ISO 20022 pain.001格式的支付指令，前提是交易方银行支持该格式）。商业信用证（UCP 600）在法律上是允许的，但对于无代码SaaS平台来说则没有实际意义，因为并未进行任何实物交易；备用信用证则仅可用于企业合同中的履约担保。来自Stripe Billing和Paddle的每日商户结算款项，根据各自的结算协议通过卡支付/ACH/SEPA/SWIFT方式接收，然后被存入百慕大运营账户，最后通过MT103支付流程进行分配，以优化美元与百慕大元之间的转换成本。与获得BMA许可的银行（如Butterfield、HSBC Bermuda）签订的直接外汇远期合约（标准形式），用于对冲USD/GBP和USD/EUR净收入转换风险——无需BMA批准，但需遵守标准的ISDA或当地主协议规定。以美元对英镑或美元对欧元为交易货币的交叉货币互换（固定/浮动利率腿）用于匹配云计算基础设施及承包商费用的现金流——在百慕大法律下，经董事会授权并已在财务报表中作出适当披露，属于允许情形。通过非伯尔姆达许可的交易商进行异质货币对（如巴西雷亚尔、巴西新雷亚尔、印度卢比）的不可交付远期交易——当BMD/USD平价使得境内远期交易不再必要时，这种交易方式就是允许的；由于1:1的货币挂钩制度，BMD/USD配对本身无需进行对冲。

第一部分 – 公司识别 公司名称、公司编号、百慕大注册办事处地址、成立日期及主要营业地点。 请提供准确的百慕大注册办公室地址；不得将海外运营总部列为注册办公室。 逾期提交罚款为100美元，每日额外罚款10美元，最高不超过1000美元。未能按时提交还可能导致公司被取消注册并解散。

第三部分 – 股本与股东 核准股本、已发行股本、股份类别、已支付对价以及持有任何类别股份5%或以上的股东。 国家发行的股份授予非居民股东，并涉及货币。对于非现金对价，需附上描述及估值方法。 逾期提交罚款为100美元，每日额外罚款10美元，最高不超过1000美元。未能按时提交还可能导致公司被取消注册并解散。
第四部分 – 主要业务活动 豁免公司的主要业务活动描述及其是否在百慕大开展业务。 状态：“在百慕大不从事任何商业活动；所有商业运营均在百慕大境外进行。” 使用 ISIC 第4版代码 6201。 逾期提交罚款为100美元，每日额外罚款10美元，最高不超过1000美元。未能按时提交还可能导致公司被取消注册并解散。

转让定价与经济实质

主文档/本地文档门槛: 百慕大根据当地税法不设转让定价文档要求，因为该地没有企业所得税。然而，若跨国集团在英国或其他海外设有业务且其海外申报门槛适用（例如，当英国集团收入超过2亿英镑且关联方交易超过2000万英镑时，通常适用英国本地文件门槛；若公司间交易超过500万英镑，则可能需要准备相关文件），则必须保留同期转让定价文档。作为实际操作的参考标准，当年度公司间许可费或服务费超过100万美元时，应准备相关文档。

经济实质审查范围: 百慕大经济实质规例（ESR）适用于从事相关业务的豁免公司，包括知识产权持有、分销与服务中心、融资与租赁以及纯粹的持股业务。若一家无代码网站构建公司属于相关实体且并非在其他税务管辖区设有税务居民身份，则必须证明其在百慕大具备充分的经济实质。若该公司在其他司法管辖区设有税务居民身份，则必须每年提交一份ESR声明，确认其境外税务居民身份，并提供税务居民身份证明书。违反相关规定将面临重大处罚，并需与境外税务机关进行信息交换。

致命合规红线与董事个人责任

经济实质不合规

法定制裁: 罚款为1万迪拉姆，每额外一天不合规将额外罚款1万迪拉姆；对于文件不符合要求的情况，将处以最高5000迪拉姆的罚款，每额外一天罚款500迪拉姆。注册官可发出合规通知，最终注销该公司。

董事个人责任: 明知允许不合规的董事，可能需承担民事罚款责任；在作出虚假声明的情况下，最高可被判处五年监禁，并处以最高不超过5万迪拉姆的罚款。
反洗钱/受益所有权违规

法定制裁: 罚款最高可达5万美元；逾期提交罚金最高为每天500美元；账户可能被冻结或支付处理器可能被终止。部长可撤销税务保证。

董事个人责任: 董事及受益所有人若涉及洗钱行为，可能面临最高达50万迪拉姆的个人罚款及最高20年的监禁，还可能被处以民事资产追索和旅行禁令。
外国司法管辖区的逃税行为

法定制裁: 英国税务海关总署（HMRC）可就归属于英国的利润按25%征收英国公司税，并可就故意隐瞒行为处以最高达税款100%的滞纳金和利息。HMRC还可发出追缴通知和加速付款通知。

董事个人责任: 董事及股东可能因未能防止逃税行为而根据英国《2017年刑事财政法》被追究刑事责任；可处以无限额罚款，并最高判处五年监禁。英国税务海关总署（HMRC）还可能发出董事资格取消令或揭开公司面纱。
迟报 / 注册代理人失职

法定制裁: 逾期提交罚款为100美元，每日额外罚款10美元（最高不超过1000美元）；公司若持续违约，将丧失良好状态并可能被注销。

董事个人责任: 董事可能因公司注销后发生的债务而承担个人责任，并可能被禁止在百慕大担任董事。
