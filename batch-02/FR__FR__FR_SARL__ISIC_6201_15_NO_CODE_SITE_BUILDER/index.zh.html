官方税号申请基础设施

      

        
主管税务局
法国财政部（DGFiP）；企业纳税人可通过 impots.gouv.fr / professionnels.impots.gouv.fr 登录；公司设立及税务登记通过企业单一窗口（Guichet Unique）在 formalites.entreprises.gouv.fr 完成；非居民实体如无法国常设机构，可通过外国企业税务服务处（SIEE）或通过欧洲统一申报系统（OSS）平台进行增值税登记。

        
电子政务申报门户
在这家有限责任公司成立之后，Guichet Unique会将相关文件提交给商业与公司注册局（RCS）和DGFiP。后者会自动颁发SIREN号码（9位数字）、SIRET号码（14位数字）、NAF/APE代码（6201Z）以及欧盟内部增值税号码（FR + 2位控制码 + SIREN）。对于没有法国注册办事处的外国实体，申请人必须向SIE/SIEE提交3559-SD表格，并提供有关其外国法律存在性、任何外国增值税注册情况、必要时的法国税务代表任命以及法国应税活动描述的相关证明。增值税号码通常在验证后15至30天内发放，自应税业务开始之日起生效。

      

      
税号代号与申请路径: 实体层级征税；法国的SARL公司属于公司所得税（IS）纳税人，适用25%的基准税率，对于年营业额不超过1000万欧元的公司，年度应税利润前42,500欧元部分可享受15%的优惠税率；实行地域性原则，仅对源自法国境内机构或经营活动的利润征税，而外国分支机构的利润通常免税，外国分支机构的亏损不得抵扣。 — 在这家有限责任公司成立之后，Guichet Unique会将相关文件提交给商业与公司注册局（RCS）和DGFiP。后者会自动颁发SIREN号码（9位数字）、SIRET号码（14位数字）、NAF/APE代码（6201Z）以及欧盟内部增值税号码（FR + 2位控制码 + SIREN）。对于没有法国注册办事处的外国实体，申请人必须向SIE/SIEE提交3559-SD表格，并提供有关其外国法律存在性、任何外国增值税注册情况、必要时的法国税务代表任命以及法国应税活动描述的相关证明。增值税号码通常在验证后15至30天内发放，自应税业务开始之日起生效。

    

    

      
默认税务分类与身份选举

      

        
默认税务归类
实体层级征税；法国的SARL公司属于公司所得税（IS）纳税人，适用25%的基准税率，对于年营业额不超过1000万欧元的公司，年度应税利润前42,500欧元部分可享受15%的优惠税率；实行地域性原则，仅对源自法国境内机构或经营活动的利润征税，而外国分支机构的利润通常免税，外国分支机构的亏损不得抵扣。

        
支持身份选举表单
法国没有美国式的“查盒”选择权。可选择的税务安排包括：（i）符合条件的家庭股份有限公司（SARL de famille）可依据《法国税法典》（CGI）第239条之二的规定，被视同为透明合伙企业进行征税；（ii）可选择增值税合并（统一纳税人，assujetti unique）制度，依据《法国税法典》第256条C款规定；（iii）法国母公司持有子公司至少95%股份时，可选择法国财政整合（intégration fiscale），依据《法国税法典》第223条A款规定；（iv）可选择按实际收款缴纳增值税（taxes sur les encaissements），依据《法国税法典》第269条；（v）不允许选择性地进行混合结构错配的反向调整，且根据《法国税法典》第212条之二B款规定的ATAD 2反混合规则，禁止双重扣除以及“扣除但不包含”结果。

外汇管制与央行政策诊断

      

        
经常项目兑换自由度
法国对欧元实行经常账户和资本账户的完全可兑换。根据《欧洲联盟运行条约》第63条，成员国之间以及成员国与第三国之间的资本流动和支付均不得设置任何限制。对于资本认购、利润分配、贷款偿还、清算所得、特许权使用费支付以及服务费支付等，均无需取得外汇管制许可或中央银行牌照。经常账户交易，包括法国SARL向非居民发行的发票，均可自由以欧元或外币支付。资本账户交易，包括境外股本注入和境外股权偿还，同样无需外汇审批。SARL的利润汇出在外汇层面不受限制，但实际操作中仍存在若干障碍：年度财务报表须经股东批准；法定准备金须按利润的5%计提，直至达到股本的10%；若净资产低于股本加不可分配储备，则禁止分配利润；付款银行须根据《法国货币与金融法》第L.561-1条及其后条款完成反洗钱/了解你的客户（AML/KYC）及资金来源核查。不存在强制性的事先税务清关证明，不存在汇款额度限制，也不存在强制兑换要求。

        
出口外汇强制结汇要求
在法国，没有关于出口收入上缴的法定规定，也没有强制性的回国时间要求，也不存在对出口收入的兑换比例要求。出口和跨境服务收入可以保留为欧元，或者存入由法国或欧盟银行持有的外币账户中。强制兑换比例为0%。唯一适用的义务是银行为国际收支目的向法国银行进行统计报告，以及遵守欧盟的制裁措施和反洗钱规定。对于目标公司来说，该公司是一家无需编码的网站构建商，通过 Stripe Billing 和 Paddle 等支付服务提供商来销售软件订阅服务。其跨境服务收据的处理方式与商品出口相同：无需兑换外汇，没有时间限制，也无需进行转换操作。

      

      
央行监管: 法国国家银行（BdF）；法国的外汇与货币支付政策由法国国家银行、经济部下属的财政部总署（DG Trésor）以及作为银行和支付机构审慎监管机构的金融稳定与解决委员会（ACPR）共同执行。法国不存在独立的外汇管理部门。

        在SARL注册前，初始股本的出资应通过SWIFT MT103汇款至法国银行账户（账户名称为“正在成立的公司”，即“SARL en constitution”），并明确标注为“冻结股本”。若出资方为非欧盟经济区（EEA）境外股东，则通过SWIFT MT103汇款；若出资银行位于EEA地区，则通过SEPA信用转账。受益银行将出具法定存单。汇款指令应注明“现金出资 / 股本认购 / 正在成立的SARL”。在对外支付统计分类中，该笔交易须由银行归类为“非居民向法国居民企业进行的直接投资资本出资”；若银行系统要求填写交易目的代码或国际收支统计分类，则应选择法国银行报告菜单中的“直接投资/股权参与”代码，而非服务、贷款或收入类代码。若出资为外币，收款银行按市场即期汇率进行兑换，无需外汇管制审批。该出资款项须在商业法院完成SARL注册前保持冻结状态。注册完成后，账户将转为运营账户。注册后增资时，仍采用相同汇款路径，标注为“资本增加”，银行将要求提供股东会决议、更新后的公司章程、公证文件、Kbis文件以及更新后的受益所有权登记文件。相关文件验证材料包括资金来源证明、每位出资股东的身份证明、股份认购明细以及由法定代表人提供的注册文件或证书。对于欧盟经济区（EEA）供应商、承包商及订阅服务提供商的付款，应使用SEPA贷记转账；如情况紧急，可采用即时SEPA贷记转账；对于大额欧元银行间支付，则应使用TARGET2结算系统。付款指令应以ISO 20022 XML格式编制，包含收款方的IBAN和BIC，以及汇款信息中的原始发票或采购订单编号。对于非欧盟经济区的付款，应使用SWIFT MT103格式，注明收款银行的SWIFT BIC、收款账户（以当地格式或IBAN格式为准），并附上明确的说明，例如“服务费 / 发票编号X / 合同编号Y”；若收款银行需单独开立账户，则应使用MT202 COV担保付款。贸易及服务债务的结算绝不能通过现金、未注册的虚拟货币转账或壳公司支付中介进行，除非该中介为受监管的金融机构。根据法国法律，商业信用证是合法的，但对无代码软件企业而言通常效率较低；若供应商因实物基础设施或采购需求要求提供信用证，应开具符合UCP600条款的不可撤销的单据信用证，以欧元计价，见票即付，并由一家欧洲银行提供确认。所有对外付款均需经过制裁筛查、反洗钱（AML）审查以及银行账户使用情况的监控。以欧元/美元、欧元/英镑及其他可兑换货币对为基础的外币即期远期合约（FX outright forwards），可在ISDA主协议或银行标准企业资金管理条款下提供，其规模限于实体根据订阅收入及供应商合同实际预测的外币敞口。对于没有完全可交付市场的货币，或该有限责任公司没有本地结算账户的情况，则采用不可交付远期合约（NDF）形式进行交易。这种合约可作为对冲工具，且必须由ACPR认可的交易对手进行交易，计算与结算均以欧元为单位，但需符合已记录的基础风险敞口要求。用于对重大非欧元债务或集团间资本流动进行长期资产负债表对冲的跨境货币互换（XCCY），须符合EMIR的清算、保证金要求以及ISDA文件规定，且仅在敞口超过普通远期合约在操作上效率较低的阈值时，适用于SARL。外汇掉期（外币掉期）用于在欧元与临时非欧元政府债券头寸之间滚动短期流动性转换，此类掉期基于相同的信贷文件，并仅限于应对现金管理流动性错配，不得用于投机交易。
      

      
电商与网关结算适配度: 对于获得欧洲经济区许可的电子货币机构以及持有EMI或银行执照并获准在法国运营的金融科技银行来说，这类机构属于中等级别；例如Wise Europe、Revolut Bank UAB、Qonto和Shine等。而离岸第三国数字EMI则属于低级别。根据欧盟修订后的支付服务指令（EU）2015/2366以及法国货币与金融法，只有获得ACPR授权或获准在法国运营的欧洲经济区支付机构才能为居住在法国的法人实体提供支付账户并发行电子货币。没有法国执业权的离岸EMI无法合法地管理法国SARL的资金，银行或监管机构可能会阻止或关闭此类账户。通常，EMI不提供存款担保保护，也无法提供信贷服务，因此不适合作为股份资本托管账户的法定账户。如果其背后的合作银行是欧洲经济区认可的信贷机构，那么EMI可以作为订阅收入的辅助收款工具使用；但SARL仍应将其主要资金与资本账户保留在获得完全许可的法国或欧盟银行中。

法定制裁: 因恶意或欺诈性隐瞒而处以80%的税款处罚，逾期付款利息按每月0.40%计算，对企业所得税进行全面重新评估，并根据《反腐败法》第1741条追究刑事责任，最高可处以25万欧元罚款和七年监禁，对于有组织的欺诈行为将适用更重的加重处罚。

        
董事个人责任: 签署或唆使提交虚假财务报告的董事，须就税款及罚款承担连带责任；法院可对其实施个人破产措施、禁止其担任法国公司的董事、没收资产并禁止其出境，以及判处监禁。
