法定所得税率 (CIT)

25.0%的法国公司所得税税率（《法国财税法》第219条）适用于SARL的应税总收入，但若满足法定资格条件，则对应税收入前38,120欧元部分适用15%的中小企业优惠税率。

股息预提税 (WHT)

根据《法国公司法》第119条之二的规定，法国SARL向非法国居民企业股东支付的股息，适用25%的国内预提所得税。对于居住在法国境外的个人股东，国内预提税率为12.8%，加上适用的社会税，若该股东属于相关范围，标准PFU机制的综合税率则为30%；根据税收协定，预提税率可降至15%、10%或5%；根据欧盟母公司-子公司指令，若母公司连续24个月持有至少10%的资本，并符合2015/121/EU指令规定的反滥用条件，则完全免除预提税。

转让定价与经济实质

主文档/本地文档门槛: 5000万欧元：根据法国《税务程序法典》第L.13B条和第L.13AA条，年净营业额超过5000万欧元的法国SARL公司通常须编制并保存本地文件；当最终母公司的合并收入达到7500万欧元时，必须编制主文件和国家对国家报告。即使未达到强制性门槛，法国税务与财政署（DGFiP）也可能要求在API/数据贸易领域要求关联方交易提供充分的转让定价文件，且在缺乏本地文件的情况下，将不予采纳独立交易原则的证据。

经济实质审查范围: 法国不实施海湾式经济实质规制；然而，法国税收政策及经合组织反税基侵蚀与利润转移（BEPS）框架要求，真实经济实质是享受法国税收居民身份、税收协定待遇以及适用欧盟母公司与子公司指令的前提条件。一家在法国注册的SARL公司，若从事商业网络数据抓取及代理API网关业务，必须在法国境内保持真实的公司实体存在和决策机制，包括办公场所、运营员工、技术基础设施、通过书面合同与俄罗斯或其他境外实体进行的分包安排、银行账户、会计记录、董事会会议纪要以及反映法国实体所承担职能、资产和风险的定价政策。若存在通过人为手段将API收入转移至关联境外实体，同时声称享有法国税收协定待遇的结构，将依据《法国刑法典》第155A条、滥用权利原则以及法国一般反滥用规则被重新定性。

致命合规红线与董事个人责任

逃税及虚假申报

法定制裁: 因恶意行为处以额外税额40%的行政罚款，因欺诈手段或滥用法律行为处以80%的行政罚款，另加每月0.20%的滞纳金。根据《刑法》第1741条和第1743条，普通税务欺诈最高可处五年监禁及50万欧元罚款；情节严重，涉及有组织的欺诈行为或跨境资金通道的，最高可处七年监禁及300万欧元罚款，并没收违法所得。

董事个人责任: 根据《税务程序书》第L.267条，如果税收不足是由于故意、反复或严重的税务申报错误造成的，法国SARL的经理可能需对个人及公司共同承担公司的税务债务。刑事法院可以附加旅行禁令、禁止经营业务、资产冻结、没收以及监禁等处罚。
转让定价滥用及未文档化的集团内部交易

法定制裁: 根据《税务法》第57条进行的税务重新评估应做到公平合理，同时需支付40%的恶意行为罚款或80%的法律滥用罚款，以及每月0.20%的利息；如果缺乏相关文件，DGFiP可根据《税务法》第1735A条处以10,000欧元的固定罚款作为补充调整。

董事个人责任: 签署或指导出具虚假转移定价文件的经理可能需承担个人责任，应对税务债务负责；若出具虚假文件或滥用公司资产，还可能面临刑事制裁，包括最高5年的监禁和375,000欧元的罚款。
空壳公司与虚拟实体安排

法定制裁: 根据《 CGI法》第155A条，DGFiP可以无视那些违反权利滥用原则的实体，将其所有API/软件收益重新归属于实际受益人；此类交易无法获得条约优惠，所分配的收益将被重新认定，从而适用30%或25%的股息预扣税制度。对于法律滥用行为，行政处罚为重新计算的税额的80%，并需支付利息。如果该实体出具了虚假居住证明，则依据法国刑法第441-1条和第441-2条适用伪造罪处罚，最高可判处3年监禁，并处以45,000欧元的罚款。

董事个人责任: 如果该壳公司被用于欺诈行为，经理可能面临民事赔偿命令、最高15年的企业管理资格取消、旅行限制、伪造和逃税相关刑事起诉，以及个人资产的没收。
反洗钱不合规及加密支付渠道滥用

法定制裁: 未注册的加密货币服务活动将面临刑事罚款和监禁处罚；根据法国刑法第324-1条，洗钱行为可处以最高5年的监禁和375,000欧元的罚款，若通过专业或系统性手段实施，则处以10年监禁和750,000欧元的罚款。ACPRL/AMF还可以实施行政制裁，最高可达1亿欧元或年度营业额的10%，此外还可能导致资产被没收。

董事个人责任: 董事及实际管理者可能因洗钱行为而被个人处罚、禁止从事相关活动、被实施旅行禁令，甚至面临刑事定罪；当加密资产与个人财富混合，或公司被用作董事加密货币交易的通道时，可适用揭开公司面纱制度。
