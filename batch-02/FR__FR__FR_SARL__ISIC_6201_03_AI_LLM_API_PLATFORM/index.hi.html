2026-2028 के चरणबद्ध सुधारों के तहत, घरेलू B2B लेन-देनों के लिए अनिवार्य इलेक्ट्रॉनिक बिल जारी करना आवश्यक है; यह कार्य पोर्टाल पब्लिक डे फैक्टुरेशन (PPF) से जुड़े अनुमोदित डिमटेरियलाइज्ड प्लेटफॉर्मों के माध्यम से किया जाता है। B2B बिलों को संरचित इलेक्ट्रॉनिक प्रारूप में (EN 16931 या PEPPOL) जारी किया जाना चाहिए, ताकि इलेक्ट्रॉनिक रूप से संचार एवं ऑडिट ट्रेल सुनिश्चित हो सके। सीमा-पार B2B एवं B2C लेन-देनों की रिपोर्टिंग भी अनिवार्य है; फ्रांस में ब्लॉकचेन स्टैम्पिंग या रियल-टाइम ‘स्क्रांटिनो’ क्लीयरेंस का उपयोग नहीं किया जाता। AI API प्लेटफॉ
