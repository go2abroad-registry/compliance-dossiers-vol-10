Eine SARL ist standardmäßig dem französischen Unternehmensertragssteuergesetz (Impôt sur les sociétés) unterworfen. Foreign Exchange Regime & Central Bank Policy

Current-account convertibility

Frankreich verfügt gemäß dem EU-Recht über ein vollständig umwandelbares Euro-Währungssystem. Transaktionen im Kapitalkonten sind für Einwohner unbeschränkt, wobei Gewinnabfertigungen ohne vorherige Genehmigung erlaubt sind. Ein standardmäßiges statistisches Berichterstattung an die Banque de France gilt für Transaktionen über 100.000 €.

Export proceeds surrender rules

Französische Exporteure müssen ausländische Einzahlungen innerhalb von 90 Tagen zurückführen; es existiert weder eine verpflichtende Einlage bei der Zentralbank noch ein verpflichtender Umrechnungsquotient. Ausländische Konten können für die operative Liquidität erhalten werden.
