संरक्षित राज्य, पक्ष या अंशनाम अनिश्चित मेल के संदर्भ में अंतरराष्ट्रीय डेटा ट्रांसफर अकाउंट को ऑटोमैटिक रूप से बंद कर देता है।

Root cause: संरक्षित राज्य, पक्ष या अंशनाम अनिश्चित मेल के संदर्भ में अंतरराष्ट्रीय डेटा ट्रांसफर अकाउंट को ऑटोमैटिक रूप से बंद कर देता है।
