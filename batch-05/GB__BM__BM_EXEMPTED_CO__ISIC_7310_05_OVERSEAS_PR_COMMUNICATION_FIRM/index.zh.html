外汇管制自由度 根据1964年《货币法》，百慕大美元与美元实行1:1挂钩，属于完全可兑换货币。根据1972年《外汇管制法》，百慕大豁免公司具有“非居民”外汇管制身份，拥有持有、接收和支付外币的无限自由；对于非居民实体而言，资本账户交易与流动账户交易之间没有区别。将百慕大美元转换为美元、英镑、欧元或其他清算货币无需获得百慕大金融管理局的批准，以股息、管理费或清算分配形式向非居民股东汇发利润也允许自由进行。唯一的障碍在于文件方面：(i) 公司必须通过其持牌注册代理人提交年度合规报告，以保持非居民身份；(ii) 如资本赎回、减少或返还等资本交易必须按照标准豁免/EC表格进行申报，以维持该身份；(iii) 付款必须通过获得百慕大金融管理局许可的银行进行，该银行负责执行自身的反洗钱/客户身份识别及制裁筛查措施。不存在可兑换许可要求，普通贸易相关支付也不需事先获得百慕大金融管理局的批准，也没有最低持有期限要求。

电子政务申报门户

百慕大不颁发通用的企业税号或增值税识别号。百慕大豁免公司通过向公司注册处注册设立，注册处将颁发《公司注册证书》和唯一的公司编号；该公司编号作为百慕大所有财政和监管申报的实体识别码。设立人需提交公司章程和公司细则（表1）、合规法定声明，并支付注册费用。标准豁免公司无需在注册前取得税务清关证明。公司设立后，须履行以下义务：（i）根据1966年《豁免经营税收保护法》（EUTPA）申请《豁免公司证书》和《税收豁免证书》，该证书通常可保障公司自设立之日起至2035年期间的免税地位；（ii）如雇佣员工，须向百慕大薪酬税局（OTC）注册为雇主并缴纳薪酬税；（iii）向百慕大监管机构提交经济实质（ES）声明，如适用，还需提交经济实质申报表；（iv）向公司注册处提交年度公司报告。外国实体迁入百慕大时，须依据1981年《公司法》（外国公司延续条款）申请设立，并获得相同的证书包。

支持身份选举表单

百慕大没有类似于美国联邦税法的“查核实体”或“实体分类”选择权；实体的分类由法律明确规定（《1981年豁免公司法》和《1981年公司法》）。若一家公司的主要管理与控制在百慕大行使，该公司可选择被视为经济实质法下的税务居民，但此项选择不会产生所得税义务。根据百慕大的国内法，不存在“混合不匹配”选择权，但实体可依据属地原则和无所得税的特点，避免出现混合税务结果。根据《2025年公司所得税法》，符合范围的跨国企业集团可选择采用标准公司所得税或补充税评估，但不得选择进入EUTPA公司所得税豁免证书以豁免所涉收入的公司所得税。百慕大法律中不存在“穿透”选择权；豁免公司对于百慕大的税务目的而言并非穿透实体，尽管其非居民股东仅在其各自本国管辖范围内征税。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

在百慕大，没有增值税、商品及服务税或销售使用税。百慕大的收入来源包括：(a) 百慕大海关关税（根据1968年海关关税法，商品关税通常在0%至25%之间，酒精和烟草的关税约为20%）；(b) 工资税（由OTC机构管理的准间接就业税）；以及(c) 印花税。跨境公关服务及沟通咨询服务无需缴纳任何百慕大服务税。只有当百慕大公司在英国设立纳税实体时，英国的增值税才可能适用；向英国提供的B2B公关服务则不属于英国增值税的适用范围。

强制登记营业额门槛 (Nexus)

N/A——在百慕大，由于服务领域不征收增值税/ GST，因此不存在法定注册门槛。进口税注册仅适用于通过海关部门进口应税实物商品的进口商；该税种没有营业额限制。无论收入或员工数量如何，所有雇主都必须办理工资税注册。就英国增值税而言，未在英国设立办事处的百慕大销售商无需注册英国增值税，除非其提供的英国应税服务金额超过英国注册阈值（2024年4月1日起为90,000英镑）；向英国企业客户销售公关/通信服务通常不属于英国增值税的适用范围，需由客户承担反向收费义务。

外汇管制与央行政策诊断

经常项目兑换自由度

根据1964年《货币法》，百慕大美元与美元实行1:1挂钩，属于完全可兑换货币。根据1972年《外汇管制法》，百慕大豁免公司具有“非居民”外汇管制身份，拥有持有、接收和支付外币的无限自由；对于非居民实体而言，资本账户交易与流动账户交易之间没有区别。将百慕大美元转换为美元、英镑、欧元或其他清算货币无需获得百慕大金融管理局的批准，以股息、管理费或清算分配形式向非居民股东汇发利润也允许自由进行。唯一的障碍在于文件方面：(i) 公司必须通过其持牌注册代理人提交年度合规报告，以保持非居民身份；(ii) 如资本赎回、减少或返还等资本交易必须按照标准豁免/EC表格进行申报，以维持该身份；(iii) 付款必须通过获得百慕大金融管理局许可的银行进行，该银行负责执行自身的反洗钱/客户身份识别及制裁筛查措施。不存在可兑换许可要求，普通贸易相关支付也不需事先获得百慕大金融管理局的批准，也没有最低持有期限要求。

出口外汇强制结汇要求

在百慕大并不适用。没有法定的时间限制要求必须交还出口或服务收据，也没有强制性的兑换比例要求必须将部分外币收入转换为百慕大元。非居民百慕大豁免公司可以无限期地保留全部以美元、英镑、欧元或其他任何货币形式的收入，无论这些收入来自跨境公关委托、危机沟通咨询还是媒体收购支出。唯一的合规要求涉及会计和公司法方面：根据1981年公司法审计要求，账目必须反映外币资产对应的百慕大元价值，而注册代理提交的年度GDP/外汇管制报告则必须准确说明年末外币余额情况。如果该实体被视为外汇管制意义上的居民企业（例如某些由百慕大管理和控制的业务），则允许保留外币用于商业目的，无需满足复杂的交还条件。

央行监管: 百慕大货币局（BMA）负责执行1972年外汇管制法及外汇管制条例，并与百慕大财政部协同运作；英国议会保留最终主权，但已将审慎监管和外汇管制监督职责委托给百慕大货币局。

离岸数字新锐银行 / EMI 白名单

合规的境内资金入账流程：（1）董事会通过股东决议，批准以美元或百慕大元发行普通股或优先股；（2）非居民股东从其本国银行发起SWIFT MT103汇款至百慕大银行的美元代理账户（通常为摩根大通或花旗银行纽约分行，用于内部美元清算），收款人信息应填写百慕大豁免公司名称及账户号码；（3）汇款参考号必须明确注明“股份认购——资本注入——[公司名称]”，并包含公司的注册地址；交易类型说明应按照OECD报告准则归类至“股本资本”类别，且不得使用虚假贸易发票描述；（4）百慕大接收银行在向资本托管账户入账前，将要求提供股份分配决议及反洗钱（AML）资金来源文件包；（5）资金到位后，注册代理人须在法定30天内向公司注册处提交股份分配申报表，并向百慕大货币管理局（BMA）提交非居民外汇控制登记表；（6）英镑或欧元的注入资金，通过银行即期柜台按现行固定汇率兑换为美元或百慕大元，或存入经百慕大货币管理局一般许可设立的多币种账户；（7）在资金注入后，未经完整履行FATCA/CRS报告义务并获得银行同意，禁止向其他股东分配已认购的资本，此类资金流动可能被视为变相贷款或货币服务活动。该公关传播公司推荐的结算方式：(1) 对于向媒体平台、广播机构、出版商以及长期法律顾问/咨询顾问支付的高价值款项，采用SWIFT MT103方式；相关受益银行信息已预先验证，用途说明则写为“媒体投放合同付款”、“专业服务费用”或“分包商支付”；(2) 仅当公司需要提供付款凭证时，如采购广告资源、活动场地或广播时段，才使用商业信用证（UCP 600）方式——该信用证由汇丰银行百慕大分行或Butterfield发行，并通过伦敦或纽约的代理银行进行确认；(3) 对于来自英国和欧盟客户的定期服务费用，采用SEPA-ACH和BACS结算方式，通过英国EMI/代理账户或百慕大银行的欧洲清算合作伙伴进行结算，并设定每日自动转账指令至主要美元资金账户，以避免资金流失；(4) 对于需要快速支付的以美元计价的危机应对服务费用，采用当天即可完成的Fedwire/CHIPS方式；(5) 所有支付必须有相关的发票或合同作为依据，银行要求定期发送交易确认函，以证明真实的交易或服务关系，避免出现客户资金转拨标记；(6) 以百慕大元计价的债务结算遵循1:1的美元汇率；(7) 如果公司作为公关机构持有第三方资金作为支付代理（例如，客户广告购买资金的媒体计划转拨），则银行账本必须设为独立的客户资金信托账户，每周进行对账并接受审计，以维护公司的低风险标准银行地位。由于缺乏深度的BMD远期市场，为已承诺的保留管道提供美元/拜耳（挂钩，需按分钟报价）、美元/英镑和美元/欧元的可交付远期外汇合约，期限为3至12个月。跨境货币互换（公允价值计价）将来自英国和欧盟客户的英镑/欧元保留收入，按期限匹配且符合国际财务报告准则（IFRS）要求，转换为美元/马币基础货币。欧洲式外汇期权，用于对大型危机沟通活动预算及由事件驱动的媒体采购支出提供非对称保护不可交付远期合约（NDFs）主要用于结算来自新兴市场子公司或客户的费用，这些费用以受当地可兑换限制的货币形式收取；该NDF的名义金额则依据特定的应收款项记录进行确认多货币净额结算及集团内部资金池协议，可实现对英镑/欧元支出流与收入流的自然对冲，而无需动用银行授信额度经董事会批准的书面外汇风险管理政策，这是百慕大银行在授予任何衍生品交易权限前必须满足的条件，以及根据选定对手方银行设定评级门槛的ISDA/CSA协议执行条款

电商与网关结算适配度: 可行性评级：低至中等条件可行性。英国及全欧洲领先的电子货币机构（EMIs），如Wise Business、Currencycloud、基于Modulr的BaaS平台以及Payoneer，通常会接受符合低风险标准的百慕大豁免公司，但开户流程并非完全自动化：离岸特殊地区注册将触发加强的尽职调查（EDD），需通过百慕大公司注册处提取的UBO确认文件，或经认证的董事会决议（经 apostille 或公证），并需确认在英国或欧盟存在业务运营联系。EMIs在法律上允许收取服务费（如SEPA/ACH收款）以及小额对外承包商付款，前提是EMI的标准条款不禁止英国海外领地公司；然而，多个平台设有地理性黑名单，排除百慕大维尔岛（BVI）、BVI/BC，有时也包括百慕大，因此在开展合作前必须核实服务提供商的准入资格。EMI账户中的资金属于电子货币，而非银行存款，不纳入百慕大存款保险范围，仅部分受英国FSCS保障机制覆盖；因此，EMI仅适合作为收款或付款通道，而主要的现金管理、资本托管及流动性储备必须由百慕大一级银行或英国清算银行持有，并对超过特定阈值的EMI余额每日进行划转。法律限制：EMI不得用于接收资本认购，不得作为税收优惠结构的唯一付款代理，所有集团内部的公司间交易必须匹配相应的现金管理记录，以避免百慕大监管机构将其重新定性为存款或货币服务业务活动。

主文档/本地文档门槛: 低于7.5亿欧元（约7.5亿百慕大元）跨国企业全球收入门槛的百慕大主文件或本地文件要求并不适用；这家被豁免于相关规定的公关公司无需履行法定税务申报义务；属于相关范围的跨国企业则必须保存符合OECD标准的主文件、本地文件及CbC报告，同时还需提交CIT-1报表。

经济实质审查范围: 《2018年经济实体规定》要求任何从事相关业务的实体必须在百慕大开展实质性业务：在百慕大举行董事会会议和进行战略管理、拥有足够的员工、拥有实体办公场所，以及在百慕大产生核心收入。外部公共关系与沟通服务并不属于被认定为相关业务；然而，集团内部共享服务则构成“服务中心”，必须完全符合ESR规定。此外，英国的反规避法规（如CFC、常设机构及转移利润税）也要求实际开展商业活动并在百慕大实现实质性运营，而非仅停留在表面形式。

致命合规红线与董事个人责任

英国税收居民/常设机构

法定制裁: 英国对可归属的PE利润征收最高达25%的公司所得税；对英国股东征收CFC税；被转移利润税为25%，并附加利息及迟缴罚金，最高可达DPT金额的100%。

董事个人责任: 董事若实施欺诈性逃税，将面临个人民事处罚，并可能被提起刑事诉讼，最高可判处七年监禁；英国税务海关总署（HMRC）还可实施旅行限制和冻结资产的措施。
空壳公司 / 缺乏真实经济实质

法定制裁: ESR民事罚款金额为BMD 23,440至BMD 116,875；对持续违约行为处以每月罚款；强制注销及撤销登记；与外国税务机关自动交换信息

董事个人责任: 明知签署虚假声明的董事将面临最高达23,440马币的罚款和最高两年的监禁；法院可对其处以禁止任职或禁止出境的处罚。
逃税 / 误用税收豁免

法定制裁: 《2022年税务管理法》规定，罚款最高可达逃税金额的150%，加上法定利息及资产没收；若被定罪，最高可判处10年监禁；英国税务与海关总署（DPT）可对转移利润征收25%的税款。

董事个人责任: 董事对虚假申报承担连带责任；可处以个人没收、监禁以及被禁止在百慕大和英国担任董事的处罚
反洗钱/洗钱

法定制裁: 《犯罪所得法》1997年：经公诉定罪，可处无上限罚款及最高14年的监禁；可实施冻结令、没收令以及禁止从事受监管业务。

董事个人责任: 名义董事将面临个人刑事起诉、被没收费用、监禁、被禁止出境，以及被百慕大货币局和英国税务海关总署（HMRC）列入黑名单。
虚假申报 / 实际受益所有人违规

法定制裁: 1981年公司法规定的默认罚款最高可达1000美元，每日附加罚款；受益所有人罚款最高可达25000美元；公司注销

董事个人责任: 故意作出虚假陈述的高级管理人员将面临个人罚款及最高两年监禁，并被取消在百慕达和英国担任董事的资格。
跨境利润转移 / 转定价滥用

法定制裁: 英国对转移利润征收25%的 diverted profits税，并附加罚款；百慕大2023年企业所得税法对适用范围内的跨国企业集团征收15%的附加税；外国税务机关可对转让定价进行调整，并征收利息及罚款

董事个人责任: 未经适当转让定价审查即签署英国或欧盟财务报表的董事，将面临《公司董事剥夺资格法》规定的个人罚款及资格取消；若查明该安排属于虚假交易，则将面临刑事处罚。
