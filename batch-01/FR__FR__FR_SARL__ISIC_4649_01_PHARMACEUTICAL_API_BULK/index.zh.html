法定实缴资本与验资锁资账户流程 强制验资锁定

有限责任公司没有法定最低资本要求（可能低至1欧元）。根据《商业法典》第L.223-7条，注册时必须缴纳至少五分之一的现金出资额，剩余部分必须在五年内缴清。所认缴的资金必须存入由法国金融机构或公证处管理的锁定托管账户中，直到注册证书（Kbis）发放为止。

法国适用欧盟小型企业免税制度（“增值税小规模纳税人制度”）。对于销售有形商品（如药品原料药）的批发商，标准增值税注册营业额门槛为每年85,000欧元，注册前可容忍的上限为94,300欧元。服务活动的门槛分别为37,500欧元和41,300欧元。在法国设立的SARL公司，若采用正常的公司会计制度并希望抵扣进项税，可无条件选择在上述门槛以下进行增值税注册。对于欧盟内部远程商品销售，适用统一的欧盟年度营业额门槛为10,000欧元。对于未在法国设立的外国供应商，不存在营业额门槛：凡在法国提供商品或服务的应税供应，均需在法国注册增值税，并指定一名法国税务代表，前提是供应商的注册地位于欧盟境外。

法国已根据《法国商法典》第289条之二规定，建立了强制性的B2B电子发票和电子报税框架。根据现行法律，法国的纳税主体必须开具和接收结构化的电子发票，并通过公共发票平台（公共发票平台—PPF）或经认证的私人电子化平台（PDP）向法国国家财政与税务管理局（DGFiP）传输交易数据：大型及中型企业（大型企业及中小企业）自2026年9月1日起实施，小型企业和微型企业的实施日期为2027年9月1日。强制性格式包括Factur-X（EN 16931）、UBL和CII。该系统不采用意大利式实时财政签章机制，而是要求确保发票的完整性和可读性，并通过互操作的API（Y1/Y2流程）向行政机关传输结构化发票数据。对于药品原研材料交易，发票中必须包含海关税则编码（CN）、相关情况下GTIN/产品分类编码，以及正确的国际贸易术语（Incoterms），以避免DGFiP电子报税系统与DGDDI出口申报之间的信息不一致。

外汇管制与央行政策诊断

经常项目兑换自由度

欧元可以在经常账户和资本账户交易中完全自由兑换，但须遵守《欧洲联盟运作条约》第63至66条所规定的一般保障措施。法国在资本账户下的贸易结算、利润汇出或资本注入方面，不实施任何事先的外汇许可或行政配额制度。法国有限责任公司向非居民母公司汇出股息时，从外汇角度来看不受限制，不过仍需遵守法国的企业所得税、适用的预提税协定以及CRS/FATCA报告义务。

出口外汇强制结汇要求

在法国，对出口收入没有强制上缴或兑换规定。出口商可以在欧洲经济区的合法银行账户中保留外币收益，并可以自由将其用于营运资金或结算用途。每一笔跨境支付都会被当地信贷机构记录，以便向法国银行提供国际收支统计报告；实物出口申报则必须通过法国的海关DELTA/DX系统进行。不存在关于回运的法定时间限制。

央行监管: 法国银行（属于欧元体系和欧洲中央银行体系）；外部金融关系由财政总局根据《货币与金融法典》管理；审慎监管和反洗钱执法由法国金融监管局（ACPR，即“审慎监管与危机解决局”）负责。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性：较低至中等。无论是由法国金融监管局（ACPR）许可，还是依据PSD2规则“通行证”运营的电子货币机构（EMI），均只能提供支付账户和资金汇款服务，但不得在法国合法吸收存款、提供信贷、签发跟单信用证或为贸易工具提供担保。对于高风险的药品原料药（API）批发业务而言，EMI虽能实现一键多币种收款，但无法满足SWIFT信用证操作所需的完整结算流程，因此应将其视为次要或辅助性的支付渠道，而非主要的现金管理银行关系。

跨境清算通道与结算适配

如果以欧元交易，则流入权益必须通过SEPA/TARGET2渠道输入法国有限责任公司被冻结的资本账户；如果是美元、英镑或新元，则可通过SWIFT MT103方式进行转账，并使用MT202作为支付手段。在适用情况下，应使用ISO 20022标准中的EQUI代码来表示权益投入；对于集团内部股东贷款，则使用INTC代码。接收银行会将所得款项存入一个无利息的被冻结账户中，直到公司注册文件及KYC相关文件完成审核为止；之后，该资金方可用于日常运营。无需进行外汇授权手续；不过，对于任何跨境交易，银行必须向法国银行提交国际收支统计报告；如果制药批发业务涉及敏感行业，或者根据主权法规需要事先获得授权，则还必须向财政部提交外国直接投资相关报告。对API供应商的运营支付采用SWIFT MT103方式进行，用于跨货币资金转账；而对应方清算则通过主要货币中心银行完成，例如：美元使用Fedwire/CHIPS，人民币使用CIPS/离岸人民币，欧元内部支付则使用TARGET2。对于批量API采购合同，主要的清算渠道是依据UCP 600规定的商业信用证：法国银行通过SWIFT网络向指定对应银行发送MT700报文，需提供符合要求的运输和保险文件。贸易结算应仅通过法国企业银行账户进行，不得通过那些隐藏支付目的的加密货币平台或服务进行。对于出口业务，支付可以通过带有TRAD或INTC目的代码的MT103入站报文进行收取，相关文件则需保留以备海关和税务审计之用。即期外汇交易，以欧洲中央银行欧元参考利率为基准，实现出口收入或供应商付款的即时兑换。即期远期外汇合约（期汇），期限最长为24个月，用于锁定未来以美元、英镑或人民币计价的贸易现金流的货币兑换。对于中国大陆人民币（CNH）或印度卢比（INR）等无法进行实物交割的受限或非交割货币的非交割远期（NDFs），前提是其基础交易敞口具有市场流动性并已充分记录。用于长期API供应协议或集团内部融资中外汇现金流量期限错配对冲的跨境货币互换。欧洲式外汇期权及零成本保护性组合（对冲机制），用于限制不利汇率波动，同时在有利汇率变动时保留上涨空间，仅限资产负债表买家使用，且不涉及投机杠杆。

转让定价与经济实质

主文档/本地文档门槛: 年营业额或总资产超过4亿欧元的公司，必须提供完整的转让定价文档（主文件和本地文件）。对于规模较小的公司，若跨境关联交易金额超过15万欧元，则需提交简化版文档（表2257）。

经济实质审查范围: 法国没有专门的经济实质规制（ESR）制度，但经济实质对于税务居民身份及反滥用规则至关重要。税收协定中的总体反滥用规则（GAAR）和主要目的测试（PPT）均要求在法国存在真实的经济活动，包括经营场所、员工以及决策机制。缺乏实质内容的空壳公司可能面临条约优惠被拒绝或交易被重新定性的风险。

致命合规红线与董事个人责任

逃税

法定制裁: 刑事罚款最高达50万欧元，监禁最高5年（《刑法典》第1741条）。民事处罚：逃税金额的40%至80%，并加收每月0.2%的利息。

董事个人责任: 董事若参与了欺诈行为，可能需就公司未缴税款承担个人责任。可能面临旅行禁令、资产冻结及引渡措施。在严重情况下，最高可被判处五年监禁，并被禁止担任公司管理者。
空壳公司 / 缺乏经济实质

法定制裁: 拒绝享受税收协定待遇、交易重定性以及对视为股息征收25%的预提税。行政罚款最高可达未足额征收税款的100%（《海关法》第1729条）。

董事个人责任: 如果董事明知地协助了虚假架构，他们可能需对公司的税务债务承担连带责任。在税务调查期间，可能实施旅行禁令及禁止离开法国的限制措施。
反洗钱违规

法定制裁: 行政罚款最高可达500万欧元或年度营业额的5%（《货币与金融法典》）。洗钱犯罪的刑事处罚：最高可判处五年监禁并处以37.5万欧元罚款（《刑法典》第324-1条）。

董事个人责任: 董事若明知参与或未阻止洗钱活动，可被处以个人罚款和监禁；还可能被处以职业禁令或没收资产。
